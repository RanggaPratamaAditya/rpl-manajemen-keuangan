## 4.1 Lingkungan Implementasi

Pengembangan, pengujian, dan pengemasan rilis Sistem Manajemen Keuangan UMKM (`rpl-manajemen-keuangan`) dilaksanakan pada lingkungan kerja lokal berbasis sistem operasi Microsoft Windows dengan arsitektur prosesor 64-bit dan RAM 8 GB. Seluruh penulisan kode sumber, pengelolaan basis data, serta eksekusi pengujian dilakukan menggunakan Visual Studio Code yang terintegrasi dengan terminal PowerShell serta lingkungan virtual Python terisolasi (`.venv`) agar dependensi proyek tidak bercampur dengan paket global sistem. Pengendalian versi kode sumber dikelola melalui Git dengan alur percabangan fitur dan rilis (`fitur/*`, `rilis/v1.0.0`, `laporan/bab4`) yang terhubung ke repositori jarak jauh GitHub (`RanggaPratamaAditya/rpl-manajemen-keuangan`).

Pada sisi perangkat lunak aplikasi, sistem dibangun menggunakan bahasa pemrograman Python 3.15 dengan kerangka kerja mikro Flask sebagai pengendali rute HTTP dan mesin templat Jinja2 untuk merender antarmuka HTML. Penyimpanan data transaksi, kategori, dan akun pengguna memanfaatkan basis data relasional ringan SQLite3 yang diakses melalui modul `models.py` tanpa ORM eksternal. Untuk kebutuhan keamanan sandi dan token sesi digunakan pustaka Werkzeug, sedangkan pada lingkungan produksi aplikasi dijalankan di atas server WSGI Waitress agar stabil melayani permintaan HTTP dibandingkan server pengembangan bawaan Flask. Seluruh konfigurasi sensitif dipisahkan dari kode sumber melalui variabel lingkungan sistem operasi, yaitu `APP_ENV`, `SECRET_KEY`, `KEUANGAN_DB`, dan `COOKIE_SECURE`.

| Komponen | Perangkat / Pustaka | Versi / Spesifikasi | Peran dalam Sistem |
|---|---|---|---|
| Sistem Operasi & Terminal | Windows + PowerShell | 64-bit | Lingkungan eksekusi lokal, manajemen `.venv`, dan skrip cadangan |
| Editor & Kontrol Versi | Visual Studio Code, Git, GitHub | Git CLI + Remote GitHub | Penulisan kode, *pull request*, peninjauan kode, dan penandaan rilis `v1.0.0` |
| Bahasa Pemrograman | Python | 3.15 (`.venv`) | Runtime utama seluruh logika aplikasi dan utilitas CLI |
| Kerangka Kerja Web | Flask & Jinja2 | Terkunci di `requirements.txt` | Penanganan rute HTTP, sesi, proteksi CSRF, dan rendering halaman |
| Basis Data | SQLite3 | Bawaan Python | Penyimpanan lokal tabel `pengguna`, `kategori`, dan `transaksi` |
| Server WSGI Produksi | Waitress | Terkunci di `requirements.txt` | Menjalankan aplikasi pada mode produksi (`APP_ENV=production`) |
| Pengujian Otomatis | `pytest` | Terkunci di `requirements-dev.txt` | Eksekusi 45 unit/integrasi uji otomatis dan verifikasi rilis |

Dalam proses pengembangan, digunakan asisten kecerdasan artifisial (Google Gemini) sebagai mitra pemrograman (*vibe coding*) dengan alur kerja terkendali enam langkah: penyusunan spesifikasi, penulisan *prompt*, pembangkitan keluaran, eksekusi uji cepat, peninjauan kode, serta pencatatan ke jurnal (`jurnal/rangga.md`). Asisten AI dimanfaatkan untuk menyusun kerangka fungsi validasi, templat HTML, skenario uji `pytest`, serta merapikan struktur dokumentasi teknis dan manual pengguna. Setiap keluaran yang dihasilkan AI tidak pernah diterapkan secara langsung tanpa verifikasi; seluruh kode dan dokumentasi ditinjau baris demi baris terhadap aturan bisnis pada `PRD.md`, diuji menggunakan rangkaian `pytest` serta `tests/uji_cepat.py`, dan disesuaikan dengan lingkungan PowerShell serta skema basis data aktual sebelum digabungkan ke branch `main`.
